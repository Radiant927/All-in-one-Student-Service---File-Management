# 跨校区文件交接管理系统

> 佛山南海校区 ↔ 广州石牌校区 文件转交追踪与确认平台

## 项目简介

针对两校区之间通过校车人工转送文件的场景，提供一套完整的发起—通知—签收—追溯闭环管理方案。校区负责人在网页端登记转交信息，系统通过微信机器人自动通知对方，对方收到实物文件后在线确认，全程留痕可查。

## 功能清单

### 核心业务

| 模块 | 功能说明 |
|------|----------|
| 发起转交 | 上传文件附件、填写转交同学、校车班次、接收人等信息，一键发起 |
| 微信通知 | 发起后自动通过微信机器人推送通知给对方校区负责人，含详情链接 |
| 确认签收 | 对方收到实物后在线点击"确认收到"，可附带回执留言或异常说明 |
| 状态追踪 | 待接收 / 运输中 / 已确认 / 已逾期 / 异常，全程可视化 |
| 双向互通 | 南海 ↔ 石牌 均可发起，角色对称 |

### 辅助功能

- **逾期自动提醒**：校车预计到达后 X 小时未确认，自动补发提醒
- **签收凭证**：确认时可上传照片（签字页/实物照）作为留底
- **批量转交**：同一趟校车多份文件可批量登记
- **校车班次维护**：预设常用时刻表，发起时直接选择班次
- **自动编号**：每条记录生成唯一编号（如 `NH-SP-20260824-001`）
- **撤回编辑**：对方确认前可撤回或修改转交信息
- **数据导出**：支持按条件导出 Excel，用于月度归档对账
- **操作日志**：所有操作全程留痕，谁在什么时候做了什么都可追溯
- **移动端适配**：响应式布局，手机端可直接查看和确认

### 首页仪表盘

- 待我接收（红色数字提醒）
- 我发起的待确认
- 今日校车班次时间线
- 近 7 天交接统计图表

### 记录管理

- 多条件筛选（状态 / 时间 / 类型 / 紧急程度 / 人员）
- 关键词全文搜索
- 分页与排序

## 转交单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 文件标题 | 文本 | ✅ | 事由/标题 |
| 文件附件 | 多文件 | ✅ | PDF/Word/Excel/图片/压缩包等 |
| 文件说明 | 长文本 | ❌ | 备注详情 |
| 转交同学姓名 | 文本 | ✅ | 坐校车带文件的同学 |
| 转交同学电话 | 文本 | ❌ | 方便对方联系 |
| 校车出发时间 | 日期时间 | ✅ | 年月日 + 具体时间 |
| 预计到达时间 | 日期时间 | ❌ | 可根据发车时间自动推算 |
| 接收人姓名 | 文本 | ✅ | 对方校区接收人 |
| 接收人电话 | 文本 | ❌ | |
| 文件类型 | 下拉选择 | ✅ | 行政文件 / 教学资料 / 学生材料 / 财务票据 / 其他 |
| 紧急程度 | 下拉选择 | ✅ | 普通 / 加急 / 特急 |
| 系统编号 | 自动生成 | - | 格式：出发地-目的地-日期-序号 |

## 技术栈

### 后端
- **FastAPI** — 高性能 Python Web 框架，自动生成 API 文档
- **SQLite** — 轻量关系型数据库，零配置，适合中小规模
- **SQLAlchemy** — ORM 数据库操作
- **Pydantic** — 数据校验与模型定义
- **Python-multipart** — 文件上传支持

### 前端
- **Vue 3** — 渐进式前端框架
- **Element Plus** — 企业级 UI 组件库
- **Vue Router** — 路由管理
- **Pinia** — 状态管理
- **Axios** — HTTP 请求

### 通知通道
- **企业微信群机器人** — Webhook HTTP 推送，完全免费

## 快速开始

### 后端启动

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

API 文档地址：http://localhost:8000/docs

### 前端启动

```bash
cd frontend
npm install
npm run dev
```

访问地址：http://localhost:5173

开发环境下 Vite 会把 `/api` 请求代理到 `http://localhost:8000`，所以后端要先启动。
打包部署用 `npm run build`，产物在 `frontend/dist`。

### 微信机器人配置

在 `backend/.env` 中配置企业微信群机器人 Webhook：

```env
WECHAT_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx
```
